# Love Story

Премиальный интерактивный сайт-подарок без сборки и внешних JS-зависимостей.

## Запуск

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

Тексты, карточки и комплименты можно менять в `index.html` и `script.js`. Галерея использует `assets/memories-contact-sheet.png`.
